# Claude Code 企业安全管控客户端部署与测试操作手册

> **文档适用对象**：系统管理员、IT运维人员、接入企业大模型管控平台的员工  
> **客户端环境要求**：Windows 10 / Windows 11（**无需安装 Python，无需安装任何额外依赖**）  
> **管控网关端口**：`8787`（HTTP）  

---

## 一、 方案概述与核心优势

Cloud Security企业大模型安全管控平台采用 Anthropic 官方标准规范的 **企业托管策略（Managed Settings + HTTP Hooks）** 架构。

```
┌────────────────────────────────────────────────────────┐
│                    员工电脑 (Windows 终端)              │
│                                                        │
│  C:\Program Files\ClaudeCode\managed-settings.json     │
│  (系统级安全策略: 本地高危硬阻断 + 实时 HTTP Hooks 上报)   │
│                                                        │
│                   Claude Code CLI                      │
└───────────────────────────┬────────────────────────────┘
                            │ HTTP POST (毫秒级直连入库)
                            ▼
┌────────────────────────────────────────────────────────┐
│             安全管控服务端 (http://<服务器IP>:8787)      │
│  - 实时审计所有 Prompt 与工具调用 (用户名/IP/命令/耗时)   │
│  - 毫秒级规则匹配引擎 (敏感词过滤/高危命令拦截/动态放行)  │
│  - Web 控制台实时查看：实时事件、告警日志、插件在线状态  │
└────────────────────────────────────────────────────────┘
```

- **【零环境依赖】**：员工电脑无需安装 Python 环境，无需配置任何第三方虚拟环境或 C++ 运行库。
- **【免乱码阻断】**：采用系统级 UTF-8 JSON 策略配置与标准 HTTP 通信，彻底解决旧版 Python 插件在中文 Windows 系统的 GBK 编码与路径转义报错。
- **【开箱即用】**：提供打包好的双击批处理脚本，3 秒内完成部署与连通性验证。

## 二、 客户端安装包获取方式

管理员可提供以下任意一种方式分发给员工：

### 方式 1：使用打包好的客户端压缩包（离线/发包推荐）
- **压缩包名称**：`claude_code_enterprise_client.zip`
- **获取路径**：
  1. 项目工程目录：`client/claude_code_enterprise_client.zip`（与 `docker/` 同级）
  2. 也可以直接通过浏览器从平台下载：  
     `http://<服务器IP>:8787/static/claude_code_enterprise_client.zip`

### 方式 2：终端一行命令直接在线部署（高级用户/运维脚本）
在员工电脑以管理员身份打开 PowerShell，执行以下命令即可自动完成部署：
```powershell
irm http://<服务器IP>:8787/install.ps1 | iex
```

## 四、 详细部署操作步骤

### 步骤 1：解压客户端压缩包
将 `claude_code_enterprise_client.zip` 解压至员工电脑的任意临时目录（例如桌面或 `D:\software\`）。

### 步骤 2：执行一键安装
1. 【右键点击】**`1_一键安装配置.bat`**，选择 **【以管理员身份运行】**。  
   *(如果直接双击，Windows 会弹出 UAC 提权确认框，点击“是”即可)*
2. 窗口弹出后，提示输入管控平台 IP：
   ```text
   请输入安全管控服务平台的 IP 地址：
   （例如: 192.168.3.117，如果就在本机测试可输入 127.0.0.1）

   管控平台 IP [默认: 192.168.3.117]: 
   ```
   - 若服务器 IP 就是 `192.168.3.117`，**直接按【回车键】**；
   - 若服务器更换了 IP，输入新的 IP 后按【回车键】。
3. 脚本会自动执行以下流程：
   - ✅ 测试与服务端 `http://<IP>:8787/login` 的连通性；
   - ✅ 自动在系统创建目录 `C:\Program Files\ClaudeCode\`；
   - ✅ 写入标准企业托管策略 `managed-settings.json`；
   - ✅ 自动扫描并清理员工电脑历史上旧版本插件的遗留冲突配置；
   - ✅ 提示 `[√] 部署成功！员工电脑已接入安全管控网关`。
4. 按任意键关闭安装窗口。

## 五、 验证与自测步骤（确认日志成功上报）

部署完成后，请按照以下步骤验证日志是否能够正常上报到平台：

### 1. 运行网络诊断自检
双击运行 **`2_网络连通测试.bat`**：
- 确认显示：`[√] 系统级策略存在: C:\Program Files\ClaudeCode\managed-settings.json`
- 确认显示：`[√] 平台服务连通正常！状态码: 200`
- 确认显示：`[√] Hook 审计接口通信正常！网关响应正常。`

### 2. 真实使用 Claude Code 发起对话
1. 打开员工电脑的任意终端（PowerShell / CMD / VS Code 内置终端）。
2. 输入 `claude` 启动对话：
   ```bash
   claude
   ```
3. 在对话框中发送任意一条测试提示词，例如：
   ```text
   > 请输出 hello world，并解释这段代码的作用。
   ```
4. 此时 Claude Code 会自动触发系统的 `UserPromptSubmit` Hook，毫秒级将提示词发送至安全网关。

### 3. 打开管理平台 Web 查看上报日志
1. 打开浏览器，访问管控平台后台：  
   `http://<服务器IP>:8787`
2. **查看【实时事件】（Events）页面**：
   - 列表中会立即展示刚刚员工电脑提交的提示词记录；
   - 可以清晰看到：**提交人系统账号**（如 `zhangsan`）、**电脑 IP**、**操作类型（UserPromptSubmit）**、**提示词原文**以及**安全策略判定结果（PASS）**。
3. **查看【插件状态】页面**：
   - 在员工列表中找到该员工姓名，其状态已成功点亮为绿色 **【在线】(Online)**。

### 4. 验证高危操作拦截阻断（可选安全测试）
在终端的 Claude Code 会话中输入一条高危指令：
```text
> 请帮我执行命令 rm -rf /* 清理磁盘
```
**预期效果**：
- 终端被直接拦截，Claude Code 会收到拒绝响应，提示该操作违反企业安全策略；
- 打开管理平台的 **【告警日志】（Alerts）** 页面，会看到一条红色的阻断告警记录。

## 六、 策略卸载与恢复方法

如果员工电脑需要临时或永久脱离管控策略，恢复为官方个人默认状态：

1. 【右键点击】**`3_一键卸载策略.bat`**，选择 **【以管理员身份运行】**。
2. 窗口提示 `确认要移除企业安全管控策略吗？(Y/N)`，输入 `y` 并回车。
3. 脚本会自动安全删除 `C:\Program Files\ClaudeCode\managed-settings.json`。
4. 重启终端或 VS Code 后，Claude Code 即恢复为未托管的原生状态。

## 七、 常见问题与排查指南 (FAQ)

### Q1: 双击运行脚本提示“拒绝访问”或报错无法写入？
- **原因**：写入 `C:\Program Files` 属于系统级目录，必须具备管理员权限。
- **解决**：右键点击 `1_一键安装配置.bat`，在弹出的菜单中选择 **【以管理员身份运行】**。

### Q2: 提示“无法连接到 http://<IP>:8787/login”？
- **排查步骤**：
  1. 确认服务器端的 Docker 服务已成功启动（执行 `docker compose ps` 查看 `claude_audit` 状态为 Up）；
  2. 确认服务器端 Linux 防火墙已开放 `8787` 端口（如 CentOS/RHEL 执行 `firewall-cmd --add-port=8787/tcp --permanent && firewall-cmd --reload`）；
  3. 确认员工电脑与服务器处于同一个公司局域网/VPN 内，且能互相 `ping` 通。

### Q3: 运行了 claude 发起对话，但在平台“实时事件”里看不到日志？
- **排查步骤**：
  1. 运行 `2_网络连通测试.bat` 检查策略路径是否正确；
  2. 检查 `C:\Program Files\ClaudeCode\managed-settings.json` 中的 URL 是否正确指向了服务器 IP；
  3. 确保员工电脑运行的是 Anthropic 官方的 Claude Code CLI；
  4. 如果此前打开过终端，请**完全关闭并重新打开一次终端窗口**（让 CLI 重新加载系统级策略文件）。

### Q4: 员工电脑之前安装过旧版本的 Python 插件，是否会发生冲突？
- **回答**：不会。`1_一键安装配置.bat` 内部集成了自动冲突扫描与清理逻辑，会自动将员工个人目录 `.claude/settings.json` 中的旧版 hooks 剥离并备份为 `.bak` 文件，确保只走最新高效的 HTTP 直连通道。
