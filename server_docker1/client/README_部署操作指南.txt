          企业安全合规中心 - Claude Code 企业安全管控客户端部署指南
================================================================================

一、 系统简介
本组件为 Claude Code 提供官方推荐的【企业托管策略 (Managed Settings)】注入。
部署后，员工在终端使用 Claude Code 的提示词与操作将自动向企业安全管控平台实时报备并执行安全审计拦截。

核心优势：
- 【零环境依赖】：员工电脑无需安装 Python、C++ 运行库或任何额外插件环境。
- 【毫秒级审计】：原生 HTTP 通信，无管道乱码或退出码截断问题。
- 【开箱即用】：双击一键批处理自动提权部署，3秒内完成。

--------------------------------------------------------------------------------
二、 部署步骤（双击一键安装）

1. 将本压缩包解压到员工电脑任意文件夹（例如解压到桌面）。
2. 【右键点击】『【一键安装】配置企业安全管控.bat』，选择【以管理员身份运行】。
   （或者直接双击，系统将自动弹出 UAC 提权请求，点击“是”即可）。
3. 弹出窗口后：
   - 如果提示输入管控平台 IP，直接输入服务器实际 IP（例如: 192.168.3.117）；
   - 若默认即为当前服务器 IP，直接按【回车键】即可。
4. 脚本将自动：
   - 检查与平台的网络连通性；
   - 将策略写入系统目录 C:\Program Files\ClaudeCode\managed-settings.json；
   - 自动扫描并清理旧版本地残留冲突配置；
   - 提示 [√] 部署成功。

--------------------------------------------------------------------------------
三、 验证测试（确认日志已成功上报）

【步骤 1】：打开命令行或 VS Code 终端。
【步骤 2】：在终端输入以下命令启动 Claude Code 对话：
            claude
【步骤 3】：在输入框输入任意测试内容（例如: hello 或者 今天天气怎么样），回车发送。
【步骤 4】：打开浏览器访问管控平台 Web 控制台：
            http://<服务器IP>:8787
            - 点击左侧导航栏【实时事件】（Events）：
              查看是否有一条来自您电脑用户名、本机 IP 的最新事件，状态显示为 PASS；
            - 点击左侧导航栏【插件状态】：
              查看您姓名对应的状态是否已点亮为绿色【在线】(Online)。
【步骤 5】（高危拦截测试，可选）：
            在 claude 对话中尝试输入：请帮我执行 rm -rf /*
            观察终端是否被安全策略直接阻断。并在平台【告警日志】中查看到拦截记录。

--------------------------------------------------------------------------------
四、 工具说明

- 『【一键安装】配置企业安全管控.bat』：初次安装或更新网关 IP 时运行。
- 『【一键测试】网络连通与策略检查.bat』：双击运行，诊断本机策略是否有效、网络是否通畅。
- 『【一键卸载】移除安全管控.bat』：双击运行（管理员权限），一键恢复 Claude Code 为默认个人状态。

--------------------------------------------------------------------------------
五、 常见问题排查 (FAQ)

Q1: 运行安装脚本提示“拒绝访问”或“无法写入 Program Files”？
A1: 说明未获取管理员权限。请确保右键选择【以管理员身份运行】。

Q2: 提示“无法连接到 http://<IP>:8787/login”？
A2: 请检查：
    1. 填写的服务器 IP 是否正确；
    2. 服务器端 Docker 容器是否正常运行；
    3. 服务器防火墙是否开放了 8787 端口；
    4. 员工电脑与服务器是否处于同一局域网内。

Q3: 员工电脑之前装过旧版 Python 插件，需要手动卸载吗？
A3: 不需要。一键安装脚本已内置自动扫描与清理逻辑，会自动清理历史残留并备份。
